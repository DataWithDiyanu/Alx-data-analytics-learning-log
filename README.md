## 📊 Project 1: Supermarket Sales Analysis

### Project Overview

This is a beginner-level Data Analytics practice project completed as part of my learning journey. The objective was to analyze supermarket sales data, compare product performance, investigate regional revenue differences and develop recommendations based on the findings.

**Dataset:** A sample dataset containing 15 supermarket orders across Lagos, Abuja, and Kano. These records were created for practice purposes and do not represent actual supermarket transactions.

### Tools and Skills Used

* Google Sheets and Microsoft Excel
* Spreadsheet formulas and functions
* Revenue and average order value calculations
* Pivot tables
* Bar charts and data visualization
* Product and regional performance analysis
* Interpretation of findings and business recommendations

### Key Findings

* **Total revenue:** ₦125,700 across 15 sample orders.
* **Average order value:** ₦8,380.
* **Highest-revenue product:** Rice, generating ₦50,000.
* **Highest-quantity product:** Biscuits, with 27 units sold.
* **Highest-revenue region:** Lagos, generating ₦54,800.
* **Lowest-revenue region:** Kano, generating ₦25,500.

### Recommendations
Investigate regional sales differences by examining product availability, customer preferences, promotional activities and store accessibility. Explore opportunities to improve product sales while checking whether proposed changes would be profitable.
These are recommendations for further investigation, not confirmed explanations for the observed sales patterns.

### Project Limitations
The analysis uses only 15 sample orders. The findings are intended for learning and demonstration and should not be treated as representative of actual supermarket performance.

Additional information, including product costs, inventory records, customer preferences, and promotional expenditure, would be needed to support stronger business recommendations.

### What I Learned
Through this project, I practised using spreadsheet formulas, creating pivot tables, building charts, comparing sales performance, and communicating findings through a written report.
This project helped me understand how data can be used to investigate business questions and support decision-making.
